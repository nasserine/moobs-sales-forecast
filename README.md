# Moobs — Sales Forecasting

## Project overview

This project aims to forecast weekly sales for each store, using historical sales data and store-related information.

The objective is to build and evaluate machine learning models that predict sales **two weeks ahead**.

## Objectives

- Explore and understand the dataset.
- Build a forecasting baseline.
- Create relevant features from historical sales.
- Train and evaluate machine learning models.
- Compare model performance using appropriate metrics.

## Data

The dataset contains weekly sales observations for multiple stores.

The raw data is kept locally and is not included in this repository.

## Project status

**In progress** — data exploration and feature engineering.
